# CapiStay

Hotel reservation platform developed as a Full Stack portfolio project.

## Technology stack

### Backend
- C# / .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

### Frontend
- Next.js
- React
- TypeScript

## Project structure

- `backend/`: Backend solution and application layers.
- `frontend/`: Customer portal and administrative interface.
- `docs/`: Technical and functional documentation.
